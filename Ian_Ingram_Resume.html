Selected Projects

Speech engineering

The Amenti speech engine

  • Designed the engine that gives each figure a voice: Claude writes the reply, Gemini TTS speaks it through a Cloudflare Worker, and text streams in measures of up to 320 characters, gap-free in Web Audio, so long documents start in seconds instead of timing out.
  • Built a content-addressed audio archive in Cloudflare R2 (a hash of model, voice, style and text), so every line renders once; it survived a move from AI Studio’s 100-a-day cap to Vertex AI’s gemini-2.5-pro-tts with service-account auth and fallback.
  • Cast every figure from the roster (base voice, gender, dialect, character) into a style prompt, with per-line stage directions for multi-voice audio productions; chose the model in a blind A/B/C/D listening test.
  • Measured delivery instead of guessing: pitch analysis showed descriptive directions barely moved a shouted line (about 144 Hz against a real 262 Hz), while writing the text for the voice reached about 178 Hz.

AI product

Ask Amenti · source-grounded Q&A

  • Search-first by design: names and fragments resolve against local indexes with no model call; only a real question spends money.
  • Every quotation is checked against the text fetched that turn and marked verified, from a librarian's note, or unmatched; a tally prints even on clean answers so readers can see the check ran.
  • Answers only from shared registers (roster, library, events), so a wrong answer exposes a wrong record; this caught and fixed a figure misdated by more than a century.
